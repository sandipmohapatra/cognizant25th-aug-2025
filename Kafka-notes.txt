set JAVA_HOME=C:\Program Files\Java\jdk-1.8
set PATH=%JAVA_HOME%\bin;%PATH%


edit windows/kafka-server-start.bat file and locate the below code

wmic os get osarchitecture | find /i "32-bit" >nul 2>&1
if %ERRORLEVEL% EQU 0 (
  echo Kafka requires a 64-bit OS.
  exit /b 1
)

replace the above code with below

REM Skipping OS architecture check (WMIC removed in Windows 11)
REM Assuming 64-bit OS

terminal-1 : bin\windows\zookeeper-server-start.bat etc\kafka\zookeeper.properties
terminal-2: bin\windows\kafka-server-start.bat etc\kafka\server.properties

To check the kafka is running or not
-------------------------------------
netstat -ano | findstr 9092

TCP    0.0.0.0:9092    LISTENING


Use Kafka CLI to list topics
----------------------------
bin\windows\kafka-topics.bat --bootstrap-server localhost:9092 --list


Create a test topic 
--------------------
bin\windows\kafka-topics.bat ^
--create ^
--topic test-topic ^
--bootstrap-server localhost:9092 ^
--replication-factor 1 ^
--partitions 1



bin\windows\kafka-topics.bat --bootstrap-server localhost:9092 --list

 If test-topic appears → Kafka is running perfectly.


To publish a string to kafka topic
----------------------------------
bin\windows\kafka-console-producer.bat --broker-list localhost:9092 --topic test-topic

Type your lines of text and press ctrl+c


To view the kafka published messages (open this in new terminal)
--------------------------------------
bin\windows\kafka-console-consumer.bat --bootstrap-server localhost:9092 --topic test-topic --from-beginning
