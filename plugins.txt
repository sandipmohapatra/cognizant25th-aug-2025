The use of plugins in pom.xml is to tell Maven what tasks to perform during the build process and how to perform them.
Why we need plugins in Maven
Maven itself only provides a lifecycle (phases like compile, test, package, install, deploy).
But Maven does not know how to do these actions.
Plugins provide the actual implementation for these actions.
Without plugins, Maven cannot compile code, run tests, create JAR/WAR files, or deploy artifacts.
Uses of Plugins
--------------------------------------------
Compile Source Code
--------------------------------------------
maven-compiler-plugin compiles Java files into .class files.
Example: set Java version for compilation.
Run Unit Tests
maven-surefire-plugin runs JUnit/TestNG tests during the build.
Package the Project
maven-jar-plugin → Creates a JAR file.
maven-war-plugin → Creates a WAR file (for web apps).
Clean Build Directory
maven-clean-plugin deletes the target/ folder to start a fresh build.
Install/Deploy Artifacts
maven-install-plugin → Installs your artifact into the local repository.
maven-deploy-plugin → Uploads the artifact to a remote repository.
Code Quality / Reports
maven-checkstyle-plugin, maven-pmd-plugin, maven-javadoc-plugin generate reports and enforce coding standards.
---------------------------------------------------------------------------------------------------
<build>
  <plugins>
    <!-- Compiler Plugin -->
    <plugin>
      <groupId>org.apache.maven.plugins</groupId>
      <artifactId>maven-compiler-plugin</artifactId>
      <version>3.11.0</version>
      <configuration>
        <source>17</source>
        <target>17</target>
      </configuration>
    </plugin>

    <!-- Unit Testing Plugin -->
    <plugin>
      <groupId>org.apache.maven.plugins</groupId>
      <artifactId>maven-surefire-plugin</artifactId>
      <version>3.0.0-M9</version>
    </plugin>
  </plugins>
</build>
